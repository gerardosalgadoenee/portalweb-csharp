🏆 Recomendación y Justificación Técnica Final

Tras concluir las fases de instalación, codificación de la calculadora y evaluación de métricas de rendimiento, el grupo determina de forma unánime recomendar el uso de: Visual Studio Code como el entorno óptimo para el desarrollo en C#.

Sustentación Técnica de la Elección:

La elección de Visual Studio Code como entorno de desarrollo para C# se fundamenta en criterios técnicos, funcionales y de rendimiento evaluados durante el desarrollo del proyecto. Las pruebas realizadas evidenciaron que Visual Studio Code ofrece un equilibrio adecuado entre productividad, consumo de recursos y flexibilidad para la programación moderna.

Pregunta final

¿Cuál de los tres IDE ofrece la mejor experiencia para aprender y desarrollar proyectos con el lenguaje asignado, y por qué?

Respuesta del Grupo:
Visual Studio Code con C# Dev demostró ser un entorno de desarrollo rápido, estable y fácil de configurar. La instalación del SDK de .NET y de las extensiones fue sencilla, permitiendo crear y ejecutar un proyecto de consola en C# sin inconvenientes una vez completada la configuración. El consumo de recursos fue moderado, por lo que el programa funcionó de manera fluida. Además, el autocompletado (IntelliSense) y las herramientas de depuración facilitaron la identificación y corrección de errores durante el desarrollo de la calculadora.
experiencia de aprendizaje:
VS Code por ser más ligero y amigable para estudiantes que están empezando con C#.
